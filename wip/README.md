# На паузі

`accounts.patch` — окремі акаунти (логін + пароль, повна ізоляція даних між акаунтами,
головний акаунт створює інші, перенесення наявних даних у головний). Бекенд і тести готові,
фронтенд (сторінка «Акаунт», поле логіна на вході) — не закінчено.

Відновити: `git apply wip/accounts.patch` (або `git am wip/accounts.patch`).
